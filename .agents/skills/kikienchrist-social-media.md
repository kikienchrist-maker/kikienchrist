## 4. Templates Visuels (Canva — Kit Marque)

### Kit Marque (À Créer dans Canva)
| Élément | Spécifications | Usage |
|---------|----------------|-------|
| **Logo** | PNG transparent (blanc/or/noir) | Watermark, profil |
| **Palette** | `--ink #1c1a17`, `--paper #fdfbf7`, `--gold #b8860b`, `--accent #c46b1a`, `--cream #f7f3ec` | Fond, texte, accents |
| **Polices** | Titre : `Georgia` / `Playfair Display` — Corps : `Inter` / `System UI` | Hiérarchie |
| **Styles Citation** | Fond texturé (papier) + citation or + référence livre | Instagram Carrousel, Pinterest, Facebook |
| **Styles Reel** | Overlay titre (haut), sous-titres animés (bas), CTA final (flèche + lien bio) | Instagram Reels, YouTube Shorts, TikTok |
| **Styles Pin** | 1000x1500px (2:3) — Image 60% + Texte 40% — Logo coin | Pinterest |
| **Icônes** | Croix, colombe, livre, cœur, flamme (style line art or) | Bullet points, décor |

## 6. Community Management

### Règles d'Engagement
- **Temps de réponse** : < 2h (jours ouvrés) / < 24h (weekend)
- **Ton** : Bienveillant, respectueux, non-prosélyte, écoute active
- **Modération** : Supprimer hate speech, spam, prosélytisme agressif → Répondre poliment aux critiques
- **UGC (User Generated Content)** : Encourager (repost stories, demander permission pour feed)

### FAQ Sociale (Réponses Types)
| Question | Réponse Type |
|----------|--------------|
| "Pourquoi vos livres sont-ils chers ?" | "Lulu imprime à la demande (qualité, pas de stock). Ebook/Audio à prix accessible. On cherche toujours à baisser les coûts." |
| "Est-ce que vous êtes catholiques/protestants/orthodoxes ?" | "Nos livres sont interconfessionnels — ils parlent de Dieu, pas d'une dénomination. Tous chrétiens bienvenus." |
| "Je n'ai pas d'argent pour acheter." | "Le guide '7 prières' est 100% gratuit. Les articles blog aussi. La prière n'a pas de prix." |
| "Vos livres existent-ils en [langue] ?" | "Actuellement en 9 langues (FR/EN/ES/DE/PT/IT/RU/ZH/HI). Dites-nous laquelle vous manquez !" |

### Crise / Bad Buzz (Procédure)
1. **Ne pas supprimer** (sauf contenu illégal) — Capture écran
2. **Répondre publiquement** (si factuel) : "Merci pour votre retour. Nous prenons note..."
3. **Basculer en DM** pour discussion approfondie
4. **Documenter** : Incident log (date, plateforme, contenu, action, résultat)
5. **Post-mortem** : Ajuster guidelines si nécessaire

## 7. Publicités Payantes (Meta Ads / Pinterest Ads)

### Quand Lancer (Seuils)
- **Organique stable** : ≥ 1k abonnés IG/FB, ≥ 500 visites/mois site
- **Lead Magnet validé** : Taux conversion NL ≥ 3%, coût/lead organique connu
- **Budget test** : 5-10 €/jour pendant 14 jours

### Structure Campagne (Meta Ads)
| Niveau | Configuration |
|--------|---------------|
| **Campagne** | Objectif : **Trafic** (vers site) OU **Conversions** (inscription NL / achat via CAPI) |
| **Ensemble** | Ciblage : Intérêts "Spiritualité", "Christianisme", "Développement personnel", "Prière", "Lecture" + Lookalike 1% (visiteurs site 30j) + Exclu clients existants |
| **Annonce** | Format : **Carousel** (4 cartes = 4 livres) OU **Video** (Reel 30s) + **Primary Text** court + **Headline** "4 livres pour votre foi" + **CTA** "En savoir plus" / "S'inscrire" |

### Pinterest Ads (Très Performant pour Niche Livre/Spirituel)
- **Format** : Standard Pin (2:3) + Video Pin
- **Ciblage** : Mots-clés "prière", "livres chrétiens", "spiritualité", "foi" + Actalike
- **Budget** : 3-5 €/jour (CPC souvent < 0,20€)

### Tracking & Attribution
- **UTM** obligatoire : `utm_source=facebook&utm_medium=cpc&utm_campaign=pack-4-livres&utm_content=carousel-visage`
- **Meta CAPI (Conversions API)** : Server-side tracking (Netlify Function / Vercel Edge) pour achats précis
- **Pinterest Tag** : Événements `pagevisit`, `signup`, `addtocart`, `checkout`
