## 2. Programme d'Affiliation (Structure)

### Plateforme Recommandée : **FirstPromoter** (ou **Rewardful**, **Tapfiliate**)
| Critère | FirstPromoter | Rewardful | Tapfiliate |
|---------|---------------|-----------|------------|
| **Prix** | $49/mois (jusqu'à 50 affiliés) | $49/mois | $89/mois |
| **Intégration** | Stripe, Paddle, LemonSqueezy, API custom | Stripe, Paddle, API | Large |
| **Multilingue** | ✅ Dashboard + Links | ✅ | ✅ |
| **Paiements Auto** | ✅ (PayPal, Wise, Stripe Connect) | ✅ | ✅ |
| **Tracking** | Cookie 30-90j, Last-click | Cookie 30j | Avancé |
| **Rapports** | Temps réel, exports | Basiques | Avancés |

> **Alternative Gratuite (Début)** : **Google Sheets + UTM + Paiement manuel mensuel** → Migration FirstPromoter à 20+ affiliés actifs.

### Structure Commissions
| Produit | Prix Public | Commission Affilié | Revenu Net (après frais plateforme ~5%) |
|---------|-------------|-------------------|----------------------------------------|
| **Livre Papier (Lulu)** | 13,90 € | **30% = 4,17 €** | ~9,20 € |
| **Ebook (Payhip)** | 3,99 $ | **30% = 1,20 $** | ~2,60 $ |
| **Audio (Google Play)** | 5,49 $ | **25% = 1,37 $** | ~3,90 $ |
| **Pack 4 Livres (Promo)** | 39,90 € | **35% = 13,97 €** | ~25,90 € |

### Règles Programme
- **Cookie Duration** : 60 jours (standard)
- **Attribution** : Last-click (dernier affilié cliqué)
- **Seuil Paiement** : 50 € / $ (virement mensuel auto)
- **Interdit** : Brand bidding (Google Ads sur "Kiki en Christ"), Spam, Contenu contraire aux valeurs
- **Approbation** : Manuelle (vérification contenu/qualité avant activation)

## 4. Processus Recrutement (Pipeline)

### Étape 1 : Identification (Continus)
- **Outils** : BuzzSumo, HypeAuditor, Modash, Instagram Search ("foi chrétienne", "prière quotidienne", "livres spirituels")
- **Critères** : 1k-50k abo, Engagement Rate > 3%, Audience francophone/anglophone/hispanophone, Valeurs alignées
- **Output** : Liste 50-100 prospects/mois dans Airtable/Notion

### Étape 2 : Approche (Personnalisée)
**Template Email/DM (FR)** :
```
Objet: Partenariat pour "Kiki en Christ" — 4 livres spirituels

Bonjour [Prénom],

Je suis [Votre Nom] de Kiki en Christ (4 livres pour approfondir sa foi, traduits en 9 langues).

Je suis votre contenu depuis [détail spécifique — prouve que vous l'avez vu] et j'adore votre approche sur [thème précis].

On lance un programme d'affiliation pour recommander nos livres à votre audience :
• 30% commission sur chaque vente (papier/ebook/audio)
• Cookie 60 jours, paiement auto mensuel
• Kit complet : visuels, textes, lead magnet co-brandé
• Produits validés : 4.8/5 ⭐ (127 avis), lecteurs 40 pays

Ça vous intéresserait d'en parler 10 min ? Je peux vous envoyer le kit complet.

Bien à vous,
[Votre Nom]
Kiki en Christ — kikienchrist.vercel.app
```

### Étape 3 : Onboarding (1 semaine)
1. Appel 15 min (Calendly) : Présentation, valeurs, attentes, questions
2. Création compte FirstPromoter → Envoi identifiants
3. Envoi Kit Affilié (Google Drive / Notion)
4. Premier contenu planifié ensemble (date, format, CTA)
5. Suivi J+3, J+7, J+30

### Étape 4 : Activation & Rétention
| Action | Fréquence | Objectif |
|--------|-----------|----------|
| **Newsletter Affiliés** | Mensuelle | Nouvelles offres, best-sellers, tips promo, paiements |
| **Concours Mensuel** | Mensuel | "Meilleur post du mois" → Bonus 100€ + mise en avant |
| **Nouveautés Exclusives** | Trimestriel | Accès avant-première (nouveau livre, nouvelle langue) |
| **Appel Annuel** | Annuel | Bilan, feedback, objectifs année suivante |

## 5. Partenariats Institutionnels (Églises, Paroisses, Mouvements)

### Approche Différente (Non-Commerciale)
| Partenaire | Offre | Contrepartie |
|------------|-------|--------------|
| **Paroisse / Église** | Pack 4 livres gratuit pour bibliothèque + 20% réduction paroissiens | Mention newsletter/billet + lien site |
| **Groupe Jeunes / Catéchèse** | Lead magnet "7 prières" imprimé (50 ex) + PDF | Partage réseaux + retour expérience |
| **Mouvement / Association** | Co-création contenu (ex: "Prier en couple") | Cross-promo newsletters + réseaux |
| **Séminaire / Institut** | Livres gratuits étudiants + commission bibliothèque | Recommandation programme formation |

### Processus
1. **Identification** : Annuaire diocésain, mouvements reconnus, groupes Facebook actifs
2. **Contact** : Email formel + appel → Présenter démarche (service, pas vente)
3. **Convention** : Simple (gratuit + mention) — Pas de contrat complexe
4. **Livraison** : Envoi postal (Lulu direct) ou codes Payhip gratuits
5. **Suivi** : Photos bibliothèque, témoignages, stats lien (UTM)

```text
# Église - Lead Magnet - Newsletter
https://kikienchrist.vercel.app/fr/?utm_source=partner&utm_medium=email&utm_campaign=church_leadmagnet&ref=aff_church_paris
```

### Netlify Function / Vercel Edge (Attribution Server-Side)
```typescript
// netlify/functions/affiliate-click.ts
// 1. Lire ref/UTM → 2. Set Cookie 60j (httponly, secure, samesite=lax) → 3. Redirect vers page finale
// 4. Log click (FirstPromoter API / DB) pour temps réel
```

### Webhook Vente (Plateformes → FirstPromoter)
| Plateforme | Méthode | Données |
|------------|---------|---------|
| **Lulu** | Webhook (si dispo) / API Polling | Order ID, Email, Book ISBN, Amount, Currency |
| **Payhip** | Webhook natif | `sale.completed` → Product ID, Email, Amount, Affiliate Ref (custom field) |
| **Google Play** | Play Console API (Order ID) | Manuel / Mensuel (export CSV → Import FirstPromoter) |

> **Note** : Payhip supporte `affiliate_id` custom field → Configurer dans produit Payhip → Webhook envoie direct à FirstPromoter.
