# Jejuar e orar: a poderosa combinação que Jesus nos ensinou

> **«Quando jejuares, não tenhas um ar triste... mas o teu Pai, que vê no segredo, recompensar-te-á.»** — Mateus 6:16-18

O jejum não é uma greve de fome para «forçar» Deus. É **abster-se de comida para se alimentar da Sua presença**.



## 1. Por que jejuar? (Fundamentos bíblicos)

| Objetivo | Referência | Exemplo |
| ---------------------------- | -------------- | ----------------------------------------------------- |
| **Humilhação / Arrependimento** | Joel 2:12-13   | Nínive (Jonas 3:5) |
| **Busca de orientação**   | Atos 13:2-3   | Paulo e Barnabé enviados |
| **Libertação / Proteção**  | Ester 4:16 | Ester antes de se apresentar perante o rei |
| **Avanço espiritual** | Marcos 9:29 | «Este tipo de espírito só sai pela oração e pelo jejum» |
| **Intimidade com Deus** | Mateus 4:1-2 | Jesus no deserto durante 40 dias |



## 2. Tipos de jejum bíblicos

| Tipo | Descrição | Duração típica | Dificuldade |
| ---------------------- | ------------------------------------- | ------------- | ---------------------------------- |
| **Absoluto** | Nem água nem comida | 1-3 dias, no máximo | ⚠️ Extrema (acompanhamento médico) |
| **Normal (apenas água)** | Apenas água | 1-40 dias    | Elevada |
| **Parcial (Daniel)**   | Legumes, água, sem carne/vinho/açúcar | 10-21 dias   | Moderada |
| **Intermitente** | Saltar 1-2 refeições/dia | Diário     | Baixo |
| **Meios de comunicação / Redes sociais**   | Abster-se de telemóvel, televisão, redes sociais    | Variável | Acessível |

> **Principiantes**: Comece por um **jejum parcial (tipo Daniel)** ou por **saltar uma refeição** + tempo de oração equivalente.



## 3. Calendário bíblico de jejum

| Período | Significado | Referência |
| --------------------- | ------------------------------- | ------------------ |
| **Quaresma (40 dias)** | Preparação para a Páscoa | Tradição antiga |
| **Yom Kippur** | Dia da Expiação | Levítico 23:27    |
| **Jejum de Ester**    | 3 dias antes do Purim | Ester 4:16 |
| **Jejum pessoal**   | De acordo com a orientação do Espírito Santo | Atos 13:2 |



## 4. Como combinar o jejum com a oração (Prática)

### Estrutura de um dia de jejum

| Hora     | Atividade |
| --------- | ------------------------------------------------------------------- |
| **6h-7h** | Acordar, beber água, leitura bíblica (15-20 min) |
| **7h-8h** | Oração A.C.T.S. (Adoração, Confissão, Ação de Graças, Súplica) |
| **Meio-dia**  | Pausa «maná»: versículo + oração curta (5 min) |
| **15h**   | Caminhada de oração / intercessão pela lista de necessidades |
| **19h**   | Leitura + diário de oração (respostas, impressões) |
| **21h**   | Descanso, gratidão, dormir cedo |

### Lista de oração «Jejum e Ruptura»

- [ ] Arrependimento pessoal / familiar
- [ ] Orientação para uma decisão importante
- [ ] Salvação de um ente querido não crente
- [ ] Cura (física/emocional)
- [ ] Despertar para a igreja / nação
- [ ] Proteção espiritual



## 5. Precauções médicas ⚠️

| Contra-indicação | Alternativa |
| ------------------------------------------ | ---------------------------------------- |
| Gravidez / Amamentação | Jejum parcial (uma refeição) ou jejum moderado |
| Diabetes / Hipoglicemia | Jejum moderado / redes sociais |
| Distúrbios alimentares (anorexia, bulimia) | **Não praticar jejum alimentar** — consultar |
| Medicamentos a horas fixas | Jejum parcial adaptado |
| Menores de 18 anos | Jejum de meia-dia / uma refeição com os pais     |

> **Regra de ouro**: «Mais vale obedecer nas pequenas coisas do que desobedecer nas grandes.» — Comece por pequenas coisas, seja constante.
