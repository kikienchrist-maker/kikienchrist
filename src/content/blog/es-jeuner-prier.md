# Ayunar y orar: la poderosa combinación que Jesús nos enseñó

> **«Cuando ayunes, no pongas cara triste… sino que tu Padre, que ve en lo secreto, te lo recompensará».** — Mateo 6:16-18

El ayuno no es una huelga de hambre para «obligar» a Dios. Consiste en **abstenerse de comer para alimentarse de Su presencia**.



## 1. ¿Por qué ayunar? (Fundamentos bíblicos)

| Objetivo | Referencia | Ejemplo |
| ---------------------------- | -------------- | ----------------------------------------------------- |
| **Humillación / Arrepentimiento** | Joel 2:12-13   | Nínive (Jonás 3:5) |
| **Búsqueda de orientación**   | Hechos 13:2-3   | Envío de Pablo y Bernabé |
| **Liberación / Protección**  | Ester 4:16 | Ester antes de presentarse ante el rey |
| **Avance espiritual** | Marcos 9:29 | «Esta clase de espíritus solo sale con oración y ayuno» |
| **Intimidad con Dios** | Mateo 4:1-2 | Jesús en el desierto durante 40 días |



## 2. Tipos de ayuno bíblicos

| Tipo | Descripción | Duración habitual | Dificultad |
| ---------------------- | ------------------------------------- | ------------- | ---------------------------------- |
| **Absoluto** | Ni agua ni comida | 1-3 días como máximo | ⚠️ Extrema (bajo supervisión médica) |
| **Normal (solo agua)** | Solo agua | 1-40 días    | Elevada |
| **Parcial (Daniel)**   | Verduras, agua; sin carne, vino ni azúcar | 10-21 días   | Moderada |
| **Intermitente** | Saltarse 1-2 comidas al día | Diario     | Bajo |
| **Medios de comunicación / Redes sociales**   | Abstenerse de usar el teléfono, la televisión y las redes sociales    | Variable | Accesible |

> **Principiantes**: Empiece con **un ayuno parcial (tipo Daniel)** o **saltándose una comida** + un tiempo de oración equivalente.



## 3. Calendario bíblico de ayuno

| Periodo | Significado | Referencia |
| --------------------- | ------------------------------- | ------------------ |
| **Cuaresma (40 días)** | Preparación para la Pascua | Antigua tradición |
| **Yom Kippur** | Día de la expiación | Levítico 23:27    |
| **Ayuno de Ester**    | 3 días antes de Purim | Ester 4:16 |
| **Ayuno personal**   | Según la guía del Espíritu Santo | Hechos 13:2 |



## 4. Cómo combinar el ayuno y la oración (Práctica)

### Estructura de una jornada de ayuno

| Hora     | Actividad |
| --------- | ------------------------------------------------------------------- |
| **6:00-7:00** | Despertarse, beber agua, lectura bíblica (15-20 min) |
| **7:00-8:00** | Oración A.C.T.S. (Adoración, Confesión, Acción de gracias, Súplica) |
| **Mediodía**  | Pausa «maná»: versículo + oración breve (5 min) |
| **15:00**   | Paseo de oración / intercesión por la lista de necesidades |
| **19:00**   | Lectura + diario de oración (respuestas, impresiones) |
| **21:00**   | Descanso, gratitud, acostarse temprano |

### Lista de oración «Ayuno y avance espiritual»

- [ ] Arrepentimiento personal / familiar
- [ ] Orientación para una decisión importante
- [ ] Salvación de un ser querido no creyente
- [ ] Sanación (física/emocional)
- [ ] Despertar de la iglesia / la nación
- [ ] Protección espiritual



## 5. Precauciones médicas ⚠️

| Contraindicación | Alternativa |
| ------------------------------------------ | ---------------------------------------- |
| Embarazo / Lactancia | Ayuno parcial (una comida) o ayuno moderado |
| Diabetes / Hipoglucemia | Ayuno moderado / redes sociales |
| Trastornos alimentarios (anorexia, bulimia) | **No ayunar** — consulte a su médico |
| Medicamentos a horas fijas | Ayuno parcial adaptado |
| Menores de 18 años | Ayuno de redes sociales / una comida con los padres     |

> **Regla de oro**: «Más vale obedecer en lo pequeño que desobedecer en lo grande». — Empiece poco a poco, sea constante.
