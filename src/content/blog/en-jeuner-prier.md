# Fasting and Prayer: The Powerful Combination That Jesus Modeled

> **“When you fast, do not look somber… but your Father, who sees in secret, will reward you.”** — Matthew 6:16–18

Fasting is not a hunger strike to “force” God’s hand. It is **abstaining from food in order to feed on His presence**.



## 1. Why Fast? (Biblical Foundations)

| Purpose | Reference | Example |
| ---------------------------- | -------------- | ----------------------------------------------------- |
| **Humiliation / Repentance** | Joel 2:12-13   | Nineveh (Jonah 3:5) |
| **Seeking Guidance**   | Acts 13:2-3   | Paul & Barnabas sent out |
| **Deliverance / Protection**  | Esther 4:16 | Esther before seeing the king |
| **Spiritual Breakthrough** | Mark 9:29 | “This kind can come out only by prayer and fasting” |
| **Intimacy with God** | Matthew 4:1-2 | Jesus in the wilderness for 40 days |



## 2. Types of Biblical Fasting

| Type | Description | Typical Duration | Difficulty |
| ---------------------- | ------------------------------------- | ------------- | ---------------------------------- |
| **Complete** | No food or water | 1–3 days max | ⚠️ Extreme (medical supervision required) |
| **Normal (Water Only)** | Water only | 1–40 days    | High |
| **Partial (Daniel)**   | Vegetables, water, no meat/wine/sugar | 10–21 days   | Moderate |
| **Intermittent** | Skip 1–2 meals/day | Daily     | Low |
| **Media / Social Media**   | Abstain from phone, TV, social media    | Variable | Accessible |

> **Beginners**: Start with **partial fasting (Daniel-style)** or **skipping a meal** + an equivalent amount of time spent in prayer.



## 3. Biblical Fasting Calendar

| Period | Meaning | Reference |
| --------------------- | ------------------------------- | ------------------ |
| **Lent (40 days)** | Preparation for Easter | Ancient tradition |
| **Yom Kippur** | Day of Atonement | Leviticus 23:27    |
| **Esther’s Fast**    | 3 days before Purim | Esther 4:16 |
| **Personal Fast**   | As directed by the Holy Spirit | Acts 13:2 |



## 4. How to Combine Fasting and Prayer (Practical Guide)

### Structure of a Day of Fasting

| Time     | Activity |
| --------- | ------------------------------------------------------------------- |
| **6:00–7:00 a.m.** | Wake up, drink water, read the Bible (15–20 min) |
| **7:00–8:00 a.m.** | A.C.T.S. prayer (Adoration, Confession, Thanksgiving, Supplication) |
| **Noon**  | “Manna” break: Bible verse + short prayer (5 min) |
| **3:00 p.m.**   | Prayer walk / intercession for list of needs |
| **7:00 p.m.**   | Reading + prayer journal (answers, impressions) |
| **9:00 p.m.**   | Rest, gratitude, early bedtime |

### “Fasting & Breakthrough” Prayer List

- [ ] Personal/family repentance
- [ ] Guidance for a major decision
- [ ] Salvation of a non-believing loved one
- [ ] Healing (physical/emotional)
- [ ] Revival for the church/nation
- [ ] Spiritual protection



## 5. Medical Precautions ⚠️

| Contraindication | Alternative |
| ------------------------------------------ | ---------------------------------------- |
| Pregnancy / Breastfeeding | Partial fast (one meal) or media fast |
| Diabetes / Hypoglycemia | Media fast / social media fast |
| Eating disorders (anorexia, bulimia) | **No food fast** — consult a healthcare professional |
| Medications taken at fixed times | Adapted partial fast |
| Under 18 | Social media fast / one meal with parents     |

> **Golden Rule**: “It is better to obey in small matters than to disobey in big ones.” — Start small, stay consistent.
