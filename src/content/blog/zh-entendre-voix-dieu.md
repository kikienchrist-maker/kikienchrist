# 如何在尘世的喧嚣中听见上帝的声音

> **“我的羊听我的声音，我就知道它们是我的。”** —— 约翰福音 10:27

许多基督徒会问：“上帝今天说话吗？我如何辨别祂的声音？”

## 5 个圣经标准来辨别

### 1. **上帝的声音与祂的经文相一致**

> “你的光如同灯台，你的智慧如灯。你面前的光明，你的公义如灯。你的公义如灯，你的公义如光。” —— 约翰福音 8:12

**测试**：你的“听见”是否与圣经中的明确原则相矛盾？ → **不是上帝的声音。**

| 来源           | 特征                   |
| -------------- | ---------------------- |
| **上帝**       | 从不与圣经相矛盾       |
| **我们的身体** | 为我们的欲望辩护       |
| **敌人**       | 与我们相悖，指控，混淆 |

### 2. **上帝的声音带来平安（即使在考验中）**

> “我将平安赐给你们，正如我父赐给你们一样。” —— 约翰福音 14:27

| 声音     | 内心效果                     |
| -------- | ---------------------------- |
| **上帝** | 平安、信心、清晰（即使艰难） |
| **焦虑** | 恐慌、恐惧、混乱             |
| **谴责** | 荣誉、沮丧、“你不够”         |

> **注**：圣灵的确认 = “这伤害上帝，我们悔改。”希望。谴责 = “你是个废物，放弃。”

### 3. **上帝的声音与圣灵的果实相一致**

> “圣灵的果子，就是仁爱、喜乐、和平、忍耐、恩慈、良善、信实、温柔、节制。” —— 加拉太书 5:22-23

**问题**：这种方向是否在我的身上和周围产生这些果实？

### 4. **上帝的声音通过社区得到证实**

> “在众多的顾问中，有成功的。” —— 哥林多前书 15:22

**实践**：与成熟的精神导师、牧师或成熟的朋友分享你认为听到的。

### 5. **上帝的声音引导我向基督和祂的荣耀前进**

> “我是道路、真理、生命。” —— 约翰福音 14:6

**测试**：这种方向是否使我更接近耶稣？祂是否得到荣耀？

## 🔍 3 个常见的陷阱

| 捷径                               | 真相                                   |
| ---------------------------------- | -------------------------------------- |
| **“上帝让我做...”** 来解释一个欲望 | 始终与圣经相一致                       |
| **寻找显眼的迹象**                 | 常常是“微弱的低语”（路加福音 19:12）   |
| **等待100%的确定性才能服从**       | 信心 = 不需要看到一切（希伯来书 11:1） |

## 🛠 实践练习：**“3 瓶过滤器”**

在采取行动之前：

1. **圣经过滤器**：是否符合圣经？
2. **平安过滤器**：有圣灵的平安吗（哥林多前书 3:15）？
3. **建议过滤器**：成熟朋友确认吗？

> **如果所有都是 ✅ → 坚信并前进。**  
> **如果一个 ❌ → 等待，祈祷，咨询。**
