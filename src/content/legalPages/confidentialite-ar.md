## 2. Données collectées

### a) Données de navigation (via cookies — voir [Politique cookies](/fr/cookies/))
- Adresse IP (anonymisée via GA4)
- Pages visitées, durée de session, provenance (referrer)
- Type d'appareil, navigateur, langue, résolution d'écran
- Pays/Ville approximatif (géolocalisation IP)

### b) Données d'inscription Newsletter
- Adresse email (obligatoire)
- Prénom (optionnel)
- Langue préférée (déduite ou choisie)
- Consentement explicite (double opt-in via Netlify Forms / MailerLite)

### c) Données de contact / Formulaire
- Nom, email, message
- Métadonnées : date, heure, IP (pour anti-spam)

### d) Données de commande (via plateformes tierces)
**Nous ne stockons AUCUNE donnée bancaire.** Les achats sont traités par :
- **Lulu** (livres papier) — leur politique de confidentialité s'applique
- **Payhip** (ebooks) — leur politique de confidentialité s'applique
- **Google Play** (audiobooks) — leur politique de confidentialité s'applique

## 4. Destinataires / Sous-traitants

Vos données peuvent être transmises à :
- **Vercel** (hébergement, logs d'accès, Edge Functions) — UE/USA, clauses contractuelles types
- **Google Analytics (GA4)** (mesure d'audience) — USA, Data Processing Amendment signé
- **Netlify** (formulaires, Functions serveurless) — UE/USA, DPA signé
- **MailerLite** (emailing newsletter) — UE, DPA signé
- **Lulu / Payhip / Google Play** (vente livres) — leurs politiques respectives

Aucun transfert hors UE sans garanties appropriées (clauses contractuelles types, décision d'adéquation).

## 5. Vos droits (RGPD Articles 15 à 22)

Vous disposez des droits suivants :
- **Droit d'accès** — Obtenir copie de vos données
- **Droit de rectification** — Corriger des données inexactes
- **Droit à l'effacement** ("droit à l'oubli") — Suppression de vos données
- **Droit à la limitation** — Gel temporaire du traitement
- **Droit à la portabilité** — Recevoir vos données dans un format structuré
- **Droit d'opposition** — Vous opposer au traitement (ex: marketing)
- **Retrait du consentement** — À tout moment pour newsletter / cookies

**Exercice des droits** : contact@kikienchrist.com (réponse sous 30 jours max)

## 6. Sécurité

- HTTPS/TLS 1.3 sur tout le site
- CSP (Content Security Policy) stricte
- Pas de stockage de mots de passe (pas de comptes utilisateurs)
- Accès aux données limité aux personnes habilitées
